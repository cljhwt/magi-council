---
name: magi-council
description: 用 MAGI 三方合议评审当前任务中的提案、方案取舍或重要决策，携带主 Agent 已知的对话背景、约束与项目记忆。适用于用户要求 MAGI、三方投票或多视角决策；不用于普通问答或自动批准外部操作。
---

将用户要评审的具体提案交给 MAGI，并利用你当前可见的上下文，避免让用户重复叙述背景。

1. 从当前可见对话、已加载的记忆和与提案有关的项目文件中提取事实、用户约束、此前决定、明确未知项。只查与当前任务有关的来源；不要扫描全机聊天目录。若需要其他聊天且宿主提供受支持的聊天读取工具，仅按用户指定范围读取。无法访问的历史明确标为未知。
2. 在临时目录写一个 UTF-8 JSON 请求：`proposal`（明确的表决提案）、`rule`（`majority` 或 `unanimous`）、`decisionContext`。背景对象包含 `host: "codex"`、可选的 `sessionId` 和 `project`、`summary`、`facts: [{"text":"已知事实","source":"当前用户消息或已读取的文件路径/位置"}]`、`constraints`、`decisions` 和 `unknowns`。列表后三项均为字符串数组。背景最多 24000 字符；保留关键证据而非整份聊天。不要把推测写成事实，来源不存在时不要杜撰编号。
3. 排除 API Key、凭证、环境文件内容及无关个人信息。告知用户将把这些相关背景交给本机 MAGI 配置的模型评估；调用仍受当前会话授权范围约束。摘要不是独立事实核查。信息缺口会改变决定时，先列出缺口，必要时询问用户。
4. 使用本技能所在目录上两级的 `scripts/consult.mjs` 调用：`node <skill-directory>/../../scripts/consult.mjs --input <request.json>`。使用绝对路径与正确的 shell 引号，不将用户文本拼成命令。脚本连接本机 `http://127.0.0.1:3088`；可用环境变量 `MAGI_SERVICE_URL` 选择另一个本机端口。它不会读取 Codex 私有历史或登录凭证。模型 Key 沿用本机 MAGI 服务配置。
5. 若服务未启动，提示先在 MAGI 项目启动服务；连接失败时不要编造三方意见。每次最多六次付费模型调用。不要无限重试。
6. 返回裁决、三方意见、少数意见、使用过的背景来源与仍未知的事实。模型意见不能覆盖用户已经明确的要求，也不能授权部署、付款、发送消息等外部操作。结果只是建议，执行仍遵循原任务授权。

如项目已有决策记录惯例，可以按该惯例保存结论供后续会话使用；否则结果留在当前聊天。需要写出完整记录时，给脚本显式传入 `--output <result.json>`。不要将敏感背景提交到公开仓库。
