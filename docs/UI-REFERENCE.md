# 经典 MAGI 屏幕重绘

2026-11-04：根据用户要求，替换首版原创网页布局，以经典「提訴／決議」多边形合议屏为视觉目标。

参考图入口：[MAGI 决议画面](https://note.com/modern_moose239/n/n6fe64e71b854)、[第 13 集画面讨论](https://note.com/akih/n/nf2653fde5f63)。检索时区分了另一种三方旋转矩形的 MAGI 画面；当前实现选择上下三块不规则多边形版本。

实现为 SVG 元素，并非把截图设为背景：BALTHASAR 上方、CASPER 左下、MELCHIOR 右下，橙框与橙线、青色单元、衬线日文标题、裁决双框。功能通过原画区域点击与辅助弹窗承接。

主屏维持 4:3 构图，手机端整体缩放，详情弹窗单列。支持键盘和关闭动效。待机、运行、失败和裁决均由应用实际状态驱动，不伪装已完成的投票。

这是依据公开参考重绘的可交互版本，不宣称与某一具体原帧逐像素一致；不同片源、画面状态及本地字体会产生差异。参考截图只用于本地核对，不加入发布文件。
